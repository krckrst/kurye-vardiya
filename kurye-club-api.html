Kurye Club

Sipariş API · POS entegrasyon kılavuzu

POS ya da adisyon yazılımınız siparişi tek bir istekle Kurye Club'a gönderir; sipariş restoranın kendi kuryesine düşer, kurye ilerledikçe durumu size bildiririz.

Nasıl çalışır

01Restoran Kurye Club uygulamasında Siparişler → POS / adisyon bağlantısı bölümünden API anahtarını alır ve POS ayarlarınıza yapıştırır.
02Kurye gerektiren her siparişi POST /siparis ile gönderirsiniz. Aynı harici_id tekrar gelirse yeni sipariş açılmaz.
03Sipariş restoranın ekranına düşer; otomatik atama açıksa vardiyadaki kuryeye kendiliğinden atanır, kuryenin telefonu çalar.
04Durum her değiştiğinde (atandı, yolda, teslim, iptal) webhook adresinize imzalı bir bildirim göndeririz.

Adres ve kimlik doğrulama

https://siparisapi-x2nr5cmyqq-ew.a.run.app

Her istekte restoranın anahtarını başlıkta gönderin. Anahtar kc_live_ ile başlar ve restorana özeldir.

X-Api-Key: kc_live_XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX
Content-Type: application/json
Anahtarı yalnızca sunucu tarafında saklayın. Restoran anahtarını yenilediğinde eskisi hemen geçersiz olur; bu durumda 401 alırsınız.

Cevap

201 Created
{ "id": "pos_…", "harici_id": "ADS-102938", "durum": "bekliyor", "kontor_bakiye": 412 }

Aynı harici_id tekrar gönderilirse 200 ve "tekrar": true ile mevcut sipariş döner; yeni sipariş açılmaz, ücret alınmaz.

Durum sorgula

GET/siparis/{harici_id}

{ "id": "pos_…", "harici_id": "ADS-102938", "durum": "yolda",
  "kurye": { "ad": "Ali Y." }, "olusturma": "2026-10-13T12:31:05Z", "teslim": null }
DurumAnlamı
bekliyorRestoran ekranında, kurye atanmadı.
atandiKuryeye atandı, paket alınacak.
yoldaKurye paketi aldı, yolda.
teslimTeslim edildi.
iptalİptal edildi.

İptal et

POST/siparis/{harici_id}/iptal

{ "neden": "Müşteri vazgeçti" }

Teslim edilmiş sipariş iptal edilemez (409). Henüz kuryeye atanmamış siparişin kontörü restorana iade edilir.

Durum bildirimi (webhook)

Durum her değiştiğinde webhook adresine POST göndeririz. 8 saniye içinde 2xx dönün; içeriği sonra işleyin.

POST {webhook_url}
X-KC-Zaman: 1791880265
X-KC-Imza: sha256=5f2b…
Content-Type: application/json

{ "olay": "durum", "harici_id": "ADS-102938", "durum": "teslim",
  "kurye": { "ad": "Ali Y." }, "zaman": "2026-10-13T12:58:40Z" }

İmzayı doğrulama

İmza, restorana anahtarla birlikte verilen whsec_… webhook imza anahtarıyla, zaman + "." + gövde metninin HMAC-SHA256 değeridir.

// Node.js
const crypto = require("crypto");
function dogrula(govdeMetni, zaman, imzaBasligi, gizli) {
  const beklenen = "sha256=" + crypto.createHmac("sha256", gizli)
    .update(zaman + "." + govdeMetni).digest("hex");
  const tazeMi = Math.abs(Date.now() / 1000 - Number(zaman)) < 300;
  return tazeMi && crypto.timingSafeEqual(Buffer.from(beklenen), Buffer.from(imzaBasligi));
}

Restoran, uygulamadaki Dene düğmesiyle adresinize {"olay":"test"} gönderebilir.

Ücretlendirme

API'den açılan her sipariş restoranın hesabından 1 teslimat kontörü düşer (sınırsız şube paketi olan restoranlarda düşmez). POS firması için ücret yoktur.
